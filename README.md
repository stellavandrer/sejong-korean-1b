# Sejong Korean 1B — Study Room

Petit site statique de révision du vocabulaire des leçons 1 à 12.

## Utilisation locale
Ouvrir `index.html` dans un navigateur.

## Publication avec GitHub Pages
1. Créer un dépôt public nommé `sejong-korean-1b` sur GitHub.
2. Ajouter `index.html` et `README.md` à la racine du dépôt.
3. Dans **Settings → Pages**, choisir **Deploy from a branch**.
4. Choisir la branche `main` et le dossier `/ (root)`, puis enregistrer.
5. Le site sera publié à l'adresse `https://stellavandrer.github.io/sejong-korean-1b/`.

La progression et les mots connus sont sauvegardés localement dans le navigateur de chaque personne (localStorage). Aucun compte ni serveur n'est nécessaire.

Contenu pédagogique retranscrit depuis la fiche de vocabulaire Sejong Korean 1B fournie en cours. Outil non officiel.

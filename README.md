# Sejong Korean 1B — Salle de révision 한국어

Site de révision du vocabulaire du manuel **Sejong Korean 1B** (leçons 1 à 12), en français.
Projet d'élèves, **non officiel** : il n'est pas affilié aux éditeurs du manuel.

## Fonctionnalités

- **Fiche** : la fiche de vocabulaire du cours, leçon par leçon. Tu surlignes les mots en touchant dessus ; ceux que tu as réussis 2 fois dans les exercices passent en vert automatiquement. Option « Cacher les traductions » pour t'auto-tester.
- **Cartes** : flashcards à retourner, avec glissement (droite = je savais, gauche = à revoir).
- **Quiz** : 20 questions à choix multiples, dans les deux sens, avec révision des erreurs.
- **Phrases** : phrases d'exemple avec un mot à compléter.
- **Syllabes** : remettre les syllabes d'un mot dans l'ordre.
- **Écriture** : écrire un mot, ou une phrase entière, en coréen.
- **Paires** et **Chrono** : jeux pour réviser en s'amusant.
- **Liste** : tous les mots, avec recherche.
- **Mes mots difficiles** : un mode qui regroupe les mots ratés.
- **Confort de lecture** : polices Atkinson Hyperlegible et Lexend, taille du texte, interligne, espacement des lettres, thème clair / sombre / contraste élevé, option pour masquer le Chrono.

Le sélecteur en haut permet de réviser les leçons 1 à 7, 8 à 12, tout, ou une leçon précise.

## Publication sur GitHub Pages

1. Dépose `index.html` à la racine du dépôt.
2. Dans **Settings → Pages**, choisis la branche `main` et le dossier `/ (root)`.
3. Le site est en ligne après une ou deux minutes.

Le site tient dans un seul fichier, sans dépendance à installer. Seules les polices de lecture se chargent depuis Internet ; sans connexion, la police standard est utilisée.

## Données et vie privée

- Aucun compte, aucun serveur : la progression (mots acquis, surlignages, record du Chrono, réglages) est enregistrée **dans le navigateur de chacun**.
- Elle n'est pas synchronisée entre appareils et disparaît si les données du navigateur sont effacées ou si l'adresse du site change.
- Rien n'est envoyé ni collecté.

## Contenu

- Le vocabulaire vient de la fiche distribuée en cours.
- Les phrases d'exemple ont été écrites pour l'entraînement : ce ne sont pas des citations du manuel et elles peuvent contenir des erreurs. En cas de doute, vérifie avec ton professeur.
